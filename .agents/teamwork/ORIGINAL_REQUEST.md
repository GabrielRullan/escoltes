## Overview
Add a comment/experience submission feature to route pages in the Escoltes Portal. Comments must capture user details without requiring login, require admin authorization before becoming publicly visible, and be deployed to Firebase Hosting with automated verification.

## Requirements

### R1. Comment Form on Route Pages (No Login Required)
Add/update the comment submission form on route pages (generated by `scripts/build_wiki_pages.py`).
- Required input fields:
  - **Nom** (Name)
  - **Email** (Email address)
  - **Branca Escolta** (Scout Unit: Castors/Fures, Llops/Daines, Pioners/Rangers, Rovers/Rutes, Caps/Monitors)
  - **Agrupament Escolta** (Scout Group)
  - **Valoració** (Rating 1-5 stars)
  - **Comentari** (Comment text)
- No user account login or password is required to submit.
- On submission, write the entry to Firebase Firestore collection `experiencies` with `authorized: false`.
- Display a clear notification to the user: *"✅ Comentari enviat amb èxit! Està pendent d'autorització per part de l'administrador per ser visible públicament."*

### R2. Admin Authorization & Display Filtering
- **Public View**: Update Firestore queries on route pages so that only comments with `authorized: true` (or legacy comments) are displayed to general visitors.
- **Admin Moderation Interface**: Create a dedicated admin page (`docs/mallorca/admin_comentaris.md`) included in `mkdocs.yml` under the Escoltisme section. This page connects to Firestore, displays all pending comments (`authorized: false`), and provides buttons for the admin to:
  1. **Aprovar (Authorize)**: Updates the Firestore document to `authorized: true`, making it publicly visible on the route page immediately.
  2. **Rebutjar / Esborrar (Delete)**: Deletes the pending comment document from Firestore.
  3. Displays a list of already authorized comments with an option to revoke/delete if needed.

### R3. Build Validation, Git Commit, and Deployment Verification
- Execute `python run_phase1.py` to regenerate all route pages and run `mkdocs build`.
- Commit changes and push to git to trigger GitHub Actions (`deploy_firebase.yml`).

- [ ] Comment form includes Name, Email, Scout Unit, Scout Group, Rating, and Comment text.

- [ ] Dedicated Admin page (`docs/mallorca/admin_comentaris.md`) lists pending comments with single-click Authorize / Delete buttons.
