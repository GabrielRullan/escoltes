# Fase 3: Omplir la Base de Coneixement

## Objectiu de la Fase
L'objectiu principal d'aquesta fase és carregar les dades de campaments i rutes històriques dins del sistema seleccionat a la Fase 2, així com dissenyar instruccions visuals senzilles per facilitar les tasques administratives recurrents.

## Àrees de Treball Clau
1. **Digitalització de Dades**:
   - Registrar tots els terrenys de campament, refugis i finques utilitzades durant els últims 3-5 anys.
   - Pujar tracks GPX i mapes de rutes d'excursió ja provades i segures.

2. **Creació de Llistes de Comprovació (Checklists)**:
   - Crear guies visuals pas a pas per dur a terme processos complexos, com ara:
     - Tramitar sol·licituds de permís a l'IBANAT.
     - Demanar transport col·lectiu gratuït al Consell de Mallorca.
     - Gestió de les autoritzacions de les famílies.
