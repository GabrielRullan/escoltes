# 📝 Compartir una Experiència o Consell d'Excursió

Heu fet una excursió o acampada amb la vostra unitat? Compartiu els vostres consells (estat del camí, fonts, punts d'ombra, recomanacions de branca) per ajudar altres caps escoltes de Mallorca.

---

## 📩 Opció 1: Enviar per Correu o WhatsApp

Podeu enviar la vostra experiència directament copiant i omplint les dades següents:

- **Ruta o Refugi:** [Nom de l'excursió]
- **Agrupament i Branca:** [Ex: AEG Eladi Homs - Llops/Daines]
- **Data de la Sortida:** [Mes / Any]
- **Puntuació (1 a 5 estrelles):** ⭐⭐⭐⭐⭐
- **Comentaris i Consells:** [Detalleu consells d'aigua, ombra, dificultat o estat del sender]

👉 **[📧 Prémer aquí per obrir el correu directament](mailto:escoltesmallorca@gmail.com?subject=Nova%20Experi%C3%A8ncia%20d%27Excursi%C3%B3%20Escoltes&body=Ruta%20o%20Refugi%3A%0AAgrupament%20i%20Branca%3A%0AData%3A%0APuntuaci%C3%B3%20(1-5)%3A%0AComentaris%20i%20Consells%3A)**

---

## 🐙 Opció 2: Creació Directa a GitHub

Si teniu compte de GitHub, podeu publicar la vostra ressenya obrint un issue ràpid:

👉 **[➕ Crear una nova Experiència a GitHub](https://github.com/GabrielRullan/escoltes/issues/new?title=Nova+Experi%C3%A8ncia+d%27Excursi%C3%B3)**

## 📋 Opció 3: Formulari de Google (En configuració)
