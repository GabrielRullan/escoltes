## 📜 4. Guia per a les Vetllades i Animació

- **Lleis del Foc de Camp**:
  1. Respectar el silenci del bosc i de les unitats veïnes.
  2. Mantenir la flama controlada i apagar completament les brases amb aigua i terra abans d'anar a dormir.
  3. Donar espai a cada branca perquè presenti la seva actuació o gags preparats durant el campament.
